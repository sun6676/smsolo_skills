# 硕士论文答辩PPT生成器

## 概述

从用户上传的论文出发，生成一套完整的硕士论文答辩材料：答辩结构 Markdown、视觉方案、视觉参考图、整页幻灯片图片，以及带演讲者备注的最终 PPTX。

最终 PPT 的可见页面内容必须全部来自生成的整页图片；除演讲者备注外，页面中不要出现任何可编辑文本、图形、表格或图表元素。

## 必须交付的产物

在一个命名清晰的输出文件夹中生成以下文件：

1. `defense_structure.md`：18-22页答辩PPT结构。
2. `visual_scheme.md`：视觉方案，包括配色、字体、版式规则和 Image Gen 提示词。
3. `visual_references/`：若干张用于确认整体风格的视觉参考图。
4. `slide_images/`：每一页最终PPT对应的一张16:9整页图片。
5. `thesis_defense.pptx`：由整页图片拼装而成、并写入演讲者备注的最终答辩演示文稿。

## 工作流程

### 1. 阅读并提炼论文

先识别用户上传的论文文件，并尽可能完整地提取可用内容。若为 PDF，重点检查封面、学校 logo、中英文摘要、目录、研究方法图、实验图表、结果分析、结论和致谢等页面。若为 DOCX，解析标题层级、正文、表格、图片说明、章节结构和文档元信息。

不要照搬论文原文。将论文中的书面化表述转化为适合答辩现场自述的口头表达：简洁、主动、重点清楚，适合8分钟左右讲完。

重点提炼以下内容：

- 研究背景与研究意义
- 现有研究不足或实际问题
- 研究目标与研究问题
- 方法设计、模型框架、技术路线或系统方案
- 数据来源、实验设计、评价指标或案例设计
- 核心实验结果与对比发现
- 创新点
- 研究结论、局限与未来展望

如果论文较长，先根据摘要、绪论、章节小结、实验结果章节和结论建立内容地图，再用论文中的图表、目录和章节标题进行核对。

### 2. 生成 `defense_structure.md`

输出一套18-22页、适合8分钟硕士答辩自述的PPT结构。每页文字要短，避免论文式长句。

每一页都要包含：

- 页码
- 页面标题
- 核心观点：1-2句短表达
- 建议展示形式：如时间线、问题链路图、研究框架图、技术路线图、对比表、流程图、结果柱状图、结论矩阵等
- 演讲者备注：20-60秒左右的口头讲稿，根据页面重要性调整长度

建议页数分配：

- 第1页：题目页
- 第2-4页：研究背景、研究意义与问题提出
- 第5-6页：研究目标、研究问题与整体技术路线
- 第7-10页：方法设计、模型框架、系统方案或核心机制
- 第11-15页：实验设计、案例设计与关键结果
- 第16-17页：创新点与讨论
- 第18-19页：结论与未来展望
- 第20页：致谢与答辩问答

根据论文实际内容在18-22页之间微调，不要为了凑页数加入弱内容。页面标题要更像答辩表达，例如使用“研究问题如何提出”，而不是机械套用“第一章 绪论”。

### 3. 使用 Image Gen 生成视觉方案

从论文封面或学校相关页面中提取或识别学校 logo。优先使用论文中已经出现的学校标识和视觉线索。如果论文中能明确学校名称，但没有提供视觉识别规范，且当前环境允许联网，则查找学校官网或官方视觉形象手册。配色判断优先依据官方来源，不要随意猜测。

生成 `visual_scheme.md`，内容包括：

- 学校、学院或学科的视觉识别线索
- 主色、辅助色和强调色；如可获得，给出 HEX 色值
- 适合中英文混排学术答辩的字体建议
- 题目页、章节页、内容页、方法页、结果页、致谢页的版式规则
- 视觉克制原则：背景干净、对比清晰、装饰少、信息层级明确
- 用于生成3-5张视觉参考图的 Image Gen 提示词

使用 Image Gen 生成若干张16:9视觉参考图，至少包括：

- 题目页风格
- 常规内容页风格
- 方法或框架页风格
- 实验结果或数据页风格
- 致谢/问答页风格

整体风格要正式、简洁、学术化，适合研究生论文答辩。学校主色应作为秩序感和识别感的来源，不要把页面做得过度花哨。

### 4. 生成所有最终幻灯片图片

根据 `defense_structure.md` 和 `visual_scheme.md`，为每一页生成一张完整的整页图片。每张图片中应包含该页所有可见文字、图示、图表和排版，不要依赖 PPT 中的可编辑对象呈现内容。

幻灯片图片要求：

- 16:9比例，建议 1920x1080 或更高分辨率。
- 标题位置、页码、边距、网格、色彩和视觉层级保持一致。
- 页面文字尽量少，用短语和关键词，不用长段落。
- 中文必须清晰可读，避免明显的乱码、错字或仿OCR失真。
- 图表与表格要为答辩重新简化，不要照搬论文中的密集表格。
- 只有在有助于解释研究逻辑时才加入示意图、流程图或数据图。

如果 Image Gen 对密集文字的渲染不稳定，应进一步减少页面文字，把解释内容放入演讲者备注。页面本身只承担“一眼看懂核心观点”的任务。

### 5. 拼装最终 PPTX

创建16:9宽屏 PPTX。每一页按以下方式处理：

1. 将对应的最终幻灯片图片铺满整页。
2. 不添加任何可见的可编辑文本框、形状、图表、表格或装饰元素。
3. 启用演讲者备注。
4. 将 `defense_structure.md` 中该页的讲稿写入演讲者备注。

除演讲者备注外，PPT页面里不要出现任何可编辑元素。可见内容必须是单张整页图片。

优先使用稳定的演示文稿处理库，或使用 Presentations 技能/工具完成 PPTX 创建、备注写入和渲染检查。拼装后必须检查：

- PPT页数与 `defense_structure.md` 一致。
- 每页都由一张铺满页面的图片构成。
- 每页演讲者备注已经写入，并与页面内容对应。
- 页面中没有额外可见的可编辑文本、图形、表格或图表对象。
- 页面文字在放映尺寸下清晰可读。

## 质量标准

最终结果应像一套真正用于研究生答辩的PPT，而不是把论文内容搬进幻灯片。优先保证答辩逻辑清楚，而不是面面俱到。

交付前检查：

- 整套结构能够在8分钟左右完成自述。
- 研究背景、研究问题、方法设计、实验结果、创新点和结论都被突出呈现。
- 视觉风格尊重学校识别系统，正式、简洁、学术化。
- 每一页都有明确作用，没有凑页。
- 演讲者备注能帮助答辩者自然讲述，而不是重复页面文字。
- 最终 PPTX 可以正常打开，且视觉效果与参考图保持一致。

## 回复用户时

完成后，简要说明输出文件夹位置，并列出已生成的 Markdown 文件、视觉参考图、幻灯片图片和 PPTX。若对学校 logo、官方色彩或视觉识别系统做了推断，必须明确说明假设来源。
